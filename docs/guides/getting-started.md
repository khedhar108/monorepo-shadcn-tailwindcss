# Getting Started

## Requirements

- Node.js **>=22.13.0** (see `.nvmrc`)
- pnpm **9.15+**

```bash
nvm use
node -v
pnpm -v
```

## Install and run

```bash
git clone <repo-url>
cd aria
pnpm install
pnpm dev:web    # http://localhost:3000
pnpm dev:docs   # http://localhost:3001
```

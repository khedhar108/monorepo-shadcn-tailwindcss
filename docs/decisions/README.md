## ADR template

Create `ADR-NNN-short-title.md`:

```markdown
# ADR-NNN: Title

**Status:** Proposed | Accepted | Superseded
**Date:** YYYY-MM-DD

## Context
What problem or choice prompted this?

## Decision
What we chose.

## Consequences
Pros, cons, follow-up work.

## References
Links to docs, external articles.
```
